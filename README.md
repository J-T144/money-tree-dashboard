# 🏦 Money Tree Bank: Fraud Detection Analytics Dashboard

A comprehensive data science application built with **Streamlit** to analyze, detect, and forecast fraudulent banking transactions for **Money Tree Bank (India)**.

## 🌟 Project Overview
This dashboard provides a 360-degree view of banking security. It leverages machine learning to identify suspicious patterns, segment customer behavior, and ensure algorithmic fairness in fraud detection.

## 🛠️ Key Features
- **Exploratory Data Analysis (EDA):** Deep dive into transaction volumes, geographical hotspots (Mumbai, Bangalore, etc.), and channel-wise behavior.
- **Fraud Classification:** Real-time prediction using Logistic Regression, Random Forest, and Decision Trees.
- **Customer Segmentation:** K-Means clustering to identify high-risk and high-value customer profiles.
- **Association Rule Mining:** Uses the Apriori algorithm to discover hidden relationships between login attempts and fraud.
- **Regression Forecasting:** Predicts expected transaction amounts to flag outliers.
- **Bias & Fairness Dashboard:** Monitors if the model unfairly targets specific demographics or occupations.

---

## 📂 Dataset Specification
The analysis is based on a simulated dataset of **50,000 transactions** including:
- **Demographics:** Age, Occupation, Location.
- **Transaction Details:** Amount, Type (Debit/Credit), Duration, Channel (ATM/Online).
- **Security Metrics:** Login Attempts, DeviceID, IP Address.

---

## 💻 Tech Stack
- **Frontend:** Streamlit
- **Data Manipulation:** Pandas, NumPy
- **Visualization:** Plotly, Seaborn
- **Machine Learning:** Scikit-learn
